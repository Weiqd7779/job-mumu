# 求職姆姆

求職姆姆是一個面向台灣求職者的「職缺證據工作站」。它不是只把職缺丟給語言模型摘要，而是先蒐集允許使用的公開資料、用程式統計技能需求，再把公司薪資背景、公開職場討論與 AI 建議分層呈現。

目標很簡單：讓使用者知道一項建議是來自多少份職缺、哪些公開來源，以及哪些內容只是輔助判讀，而不是把 AI 的流暢文字誤認成市場事實。

## 它解決什麼問題

一般求職工具常把三種不同的資訊混在一起：

- 職缺真正寫了什麼；
- 網路上的面試或工作經驗；
- AI 根據前兩者提出的準備建議。

求職姆姆把它們拆開。統計結果會同時顯示 `n/N`，論壇內容只能補充語境，不能覆蓋職缺統計；若使用者要求產生履歷，系統也只能改寫已確認的事實，缺少的資料會標成待補證據。

## 一次分析會怎麼進行

1. 使用者輸入職稱、公開 JD 網址，或直接貼上 JD 文字。
2. 系統先顯示它理解的任務、準備使用的資料來源與可能產生費用的操作。
3. 市場分析會取得允許使用的職缺，排除不相關群組後統計技能需求。
4. 報告把職缺證據、上市櫃公司薪資背景與公開論壇訊號分開展示。
5. 使用者可以排除錯誤群組並重新計算，也可以匯出報告。
6. 只有在使用者明確要求履歷時，系統才接收履歷事實並產生可追溯的草稿。

## 目前能做什麼

- 透過台灣就業通公開 API 掃描職缺並計算關鍵字。
- 分析使用者提供的單一 JD 文字或允許讀取的公開網址。
- 將職缺分群，讓使用者排除誤判後重新統計。
- 用 TWSE／TPEx 公開資料補充公司非主管薪資中位數背景。
- 用 Brave Search 取得公開論壇的標題、網址、摘要與時間，作為語境校準。
- 用 Fireworks 模型產生證據式分析與履歷草稿，並保留固定備援模型。
- 將專案、分析階段與報告版本存入 Cloudflare D1。
- 選擇性傳送不含原始 JD、搜尋文字或履歷內容的操作 metadata。

## 這個版本的邊界

- 目前是邀請制開發版本，不是完整公開 SaaS。
- 104、1111 與一般 LinkedIn 職缺不會在沒有正式授權時自動擷取。
- 薪資資料只用來提供公司背景，不代表職缺薪資，也不提供談薪結論。
- 市場比例只代表本次保留樣本，不宣稱涵蓋整個市場。
- PDF、DOCX 與圖片履歷目前要先轉成可選取文字。
- 外部 API 沒有設定、超時或達到費用上限時，部分分析會停止或降級。

## 資料與秘密如何處理

- API key 只從伺服器端環境變數讀取，不能寫進程式碼。
- `.env`、`.dev.vars`、Wrangler 本機狀態與建置輸出已排除版本控制。
- `.env.example` 只有變數名稱和示例值，不包含可用憑證。
- 履歷資料只有在使用者主動要求履歷功能時才收集，介面提供刪除功能。
- Telemetry 是可選功能；未設定 endpoint 和 token 時不會傳送。

如果你 fork 這個專案，請為自己的金鑰建立未追蹤的 `.dev.vars`，不要直接修改並提交 `.env.example`。

## 本機執行

需要 Node.js 22.13 以上。這個專案使用 Vinext、React、Cloudflare Workers 與 D1；本機登入可用開發者身分，不需要先部署 ChatGPT 登入。

```powershell
npm install
Copy-Item .env.example .dev.vars
npm run dev
```

接著開啟終端機顯示的本機網址。`DEV_USER_EMAIL` 會建立本機預覽使用者；要執行完整 AI 與論壇流程，還要在 `.dev.vars` 填入自己的 Fireworks 與 Brave 金鑰。

常用環境變數：

| 變數 | 用途 | 是否必要 |
|---|---|---|
| `APP_ENVIRONMENT` | 切換 development／production 行為 | 本機建議設定 |
| `DEV_USER_EMAIL` | 本機預覽使用者 | 本機執行需要 |
| `ALLOWED_USER_EMAILS` | 正式環境邀請名單 | 正式環境需要 |
| `FIREWORKS_API_KEY` | AI 分析與履歷產生 | 完整分析需要 |
| `BRAVE_SEARCH_API_KEY` | 公開論壇搜尋 | 論壇校準需要 |
| `TELEMETRY_ENDPOINT`、`TELEMETRY_WRITE_TOKEN` | 選擇性操作 metadata | 選用 |

## 驗證

```powershell
npm test
npm run lint
```

`npm test` 會先執行正式版建置，再檢查論壇證據去重、公司資料集與跨職類技能統計。測試不會呼叫付費 API。

## 主要結構

- `app/`：登入後工作站、報告畫面與 API 路由。
- `lib/analysis/`：職缺蒐集、分群、統計與分析管線。
- `lib/data/`：台灣就業通、公開 JD、Brave、薪資與公司資料來源。
- `lib/ai/`：Fireworks 分析與履歷證據邊界。
- `skills/career-analysis/`：分析 Agent 實際使用的規則與輸出格式。
- `db/`、`drizzle/`：D1 schema 與 migration。
- `worker/`：Cloudflare Worker 入口。

這個 GitHub 版本只保留主產品執行、必要資料、必要設定、三組核心測試與這份說明；實驗報告、一次性評估腳本、內部 Developer Console 與本機產物不在其中。
